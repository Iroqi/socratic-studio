# 迭代记录 — 2026-10-07（第七轮，第十七轮）：绿在每一台机器上

> 定时任务驱动的自由迭代（第十七轮）：clone 仓库 → 通读现状 → 深度头脑风暴 →
> 设计方案 → 实施 → 验证（含变异验证）→ 推送。代码变更在 `git log` 里可追溯。
> 本轮不从"还能加什么功能"出发，而是从**这一轮真跑出来的环境证据**出发：
> 换一台机器（不同时区、不同端口占用、不同并发度）现在跑不出 README 承诺的那个绿。

## 1. 现状盘点（先跑，再读代码）

- **基线（本沙箱 UTC）**：`npm run test:all` = **1093 项，5/6**——不是文档里写的 1668/6 全绿。
  红的是 `run.mjs:2798`「角色标签：我 / 老师，消息按拍号排、带时间」。
- **跑出来的四条环境账**（每条都复核过，不是读代码猜的）：
  1. **时区**：`run.mjs:2770` 的 fixture 写死 `2026-10-06T12:00:00+08:00`，断言的是
     `fmtDateTime`（`store.mjs:1513`，本地墙钟）的输出。fixture 用绝对时刻、断言用墙钟字符串，
     两者只在 UTC+8 相遇。实测：UTC / America/New_York / Asia/Kolkata **全红**，
     TZ=Asia/Shanghai 全绿。README「任何机器 npm run test:all 都是 6/6 全绿」这句现在是假的。
     另有一条同类：`web-smoke.mjs:1748`「同一天只有一条开头线」在 **TZ=Pacific/Kiritimati（UTC+14）
     红**（`2026-03-04T09:00:00Z` + 1h 跨了当地日历天）——同一个病，只是要到极东时区才露面。
  2. **端口**：`http-smoke.mjs:18` / `artifact-evidence.mjs:18` 用固定端口（8799 / 8860）。
     与开发服务并存、或两个套件并发跑，就 `EADDRINUSE`。而且**炸得很难看**：
     `serve.mjs:1496` 没有 `error` 监听 → Node 抛未捕获异常栈；`all.mjs` 把崩掉的套件报成
     `FAIL 0 项`，合计从 1093 掉到 939，看起来像"少跑了几百项断言"而不是"两个套件根本没跑"。
     （本轮三次并发跑就是这么撞上的，证据在 `ist.log`。）
  3. **损坏副本增殖**：`readJsonSafe`（`config.mjs:69`）每次读一个坏文件就写一份
     `*.corrupt-<毫秒>` 副本。实测：把一个 `chat.json` 写坏后连续 `getNotebook()` 6 次
     → **4 份内容完全相同的副本**。数据是资产这条口号下，"留证据"正在变成"造垃圾山"：
     右栏每刷新一次、每回合落盘一次都在读它。
  4. **两份墙钟格式化**：`store.mjs:1513 fmtDateTime` 与 `web/app.js:1503 formatTime`
     是同一个格式各写一遍（导出 Markdown 的拍号时间 与 会话流分隔线的时间）。
     没有任何钉子说它们必须一致——改了其中一份，同一件事在页面和导出里就是两个时间。
- **浏览器臂**：`test/preview/*` 四个脚本把 Edge 路径写死成
  `C:\Program Files (x86)\Microsoft\Edge\...`。本沙箱有 chromium，实测
  `--headless` + `--dump-dom` 能量到真页面几何（`vc.html` 66KB DOM），但 64MB 的
  `/dev/shm` 让它**跑几次就崩**（残留 chrome 进程把 shm 吃满）。
  结论：像素/实拍这条臂在这个环境里**不可依赖**，本轮不把它接进 `test:all`（接了就是
  假绿源），只做"能发现浏览器"的可移植性，别的不动。
- **历轮挂着的候选**：notebook 列表显示「上次聊到」相对时间——从第十一轮挂到第十六轮，
  三次 `⏸ 维持`，理由始终是"低优先"。数据其实早就齐了（`listNotebooks` 已回
  `updatedAt` + `messageCount`）。
- **本轮无新增自认代码债务**（除下面明确留下的那条：浏览器臂仍未进闸门）。

## 3. 方案与实施

### 3.1 I1 — 时区：fixture 与断言同框

- **原则**：`fmtDateTime` 渲的是**本地墙钟**，这是本机工具的正确行为，不改它。
  错的是测试**用绝对时刻做 fixture、用墙钟字符串做断言**——两个坐标系。
- `test/run.mjs` 12i：`new Date('…+08:00')` → `new Date(2026, 9, 6, 12, 0)`（本地构造），
  断言字面量 `2026-10-06 12:00` 与 fixture 同框，任何时区都成立。
- `test/web-smoke.mjs` 16 节：同一改法（含"跨天"与"同一天"两组 fixture 都按本地墙钟构造，
  小时取 09:00/10:00 避开 DST 跳变窗口）。
- **新增钉子**（防止这类账再来一遍）：
  - `run.mjs`：导出的拍号时间必须等于**本地墙钟**格式化结果（用独立算法算出期望值），
    并钉"换成 UTC 格式化就不相等"——把"这是墙钟不是 UTC"写进断言。
  - `contract-consistency.mjs` 新节：`store.mjs` 与 `web/app.js` 两份格式化函数的
    **模板必须逐字符一致**（`getFullYear/月/日 时:分` + 补零），改一份忘另一份当场红。

### 3.2 I2 — 损坏副本不增殖（`server/config.mjs`）

- `readJsonSafe` 落副本前先比对：同一 `file` 已有 `*.corrupt-*` 副本且**内容逐字节相同**
  → 不再新写（证据已在盘上），也不重复喊 `[数据损坏]`（同一段坏数据每读一次喊一次是刷屏）。
- 语义边界：**内容变了必须再留一份**（坏法换了一种，旧证据不能顶）；
  首次仍然留、仍然喊——"不静默覆盖可抢救数据"这条承诺一个字没退。
- `run.mjs` 12b 扩展：同一份坏 `notes.json` 再读 3 次 → 副本数仍为 1；写坏成**另一种内容**
  → 副本数变 2。

### 3.3 I3 — 套件不抢端口，炸了说实话

- `server/config.mjs` 新增 `findFreePort(start)`（`net.createServer` 试探 + 端口复用检查），
  或直接由 `serve.mjs` 支持 `SOCRATIC_PORT=0`…——取**显式端口回写**那条：
  `server/serve.mjs` 监听成功后把实际端口打到 stdout 一行 `LISTENING <port>`，
  两个套件起服务时传 `SOCRATIC_PORT=0`，读到该行再定 BASE。
- `serve.mjs` 加 `server.on('error')`：`EADDRINUSE` 时打一句人话（端口、被谁占的猜测、
  怎么换端口），非零退出——不再抛未捕获异常栈。
- `all.mjs`：套件退出码非 0 **且一个"通过 N 项"都没匹配到**时，报 `CRASH` 而不是 `FAIL 0 项`，
  合计行如实说明"这个套件没跑完"，避免"总数变小"被读成"断言变少"。

### 3.4 I4 — 列表显示「上次聊到」（挂账六轮）

- `server/store.mjs` `listNotebooks()`：`lastAt` = `chat.messages` 最后一条的时间戳
  （没有消息则 null）——不能用 `meta.updatedAt`（改名也刷时间，那不是"聊到"）。
- `web/app.js`：纯函数 `lastChatWords(lastAt)` → 人话（今天 / 昨天 / N 天前 / 某月某日 / 没聊过），
  **只说时间，不说数量之外和学习量**；列表行 meta 追加一行「上次聊到：昨天」。
  新会话（`messageCount 0`）明说「还没聊过」。
- 边界：相对天数按**本地日历天**差算（与 I1 同一条坐标系教训，别再埋一条时区账）。

### 4.1 实施过程中翻出来的两条（原设计里没有）

1. **I2b — 损坏副本撞名会覆盖旧证据**（本轮唯一真正的 bug 修复，起因是一条偶发红）：
   §3.2 的去重写完跑测，`换一种坏法必须再留一份` 约**每 5 次撞中 1 次**红。根因不是断言写得娇气，
   是副本名 `${file}.corrupt-${Date.now()}` 里的**毫秒不是计数器**：两次不同内容的损坏挤进同一毫秒时，
   `copyFileSync` 把前一份证据**逐字节覆盖**掉——"留证据"退化成"只留最后一份"。修法：用
   `fs.openSync(candidate, 'wx')` 抢名（撞了就 `-r<序号>` 递增，上限 1000 档），内容写进抢到的 fd。
   新增两颗钉子：钉死 `Date.now` 造**必然**撞名（不再靠运气复现），分别断言"两份都在"与
   "两种坏法各有一份字节一致的副本"。M9 验证：退回旧写法两颗一起红。
2. **`test/preview/measure-layout.py` 是一条挂在文档里的假绿**（本轮最值钱的发现）：
   README 两处把它当"真页面量过"的凭据，而它量的锚点 `#stage-chat` / `#chatInner` / `.stage-tabs`
   在「会话单列」改版后**全都不存在了**——`document.getElementById` 返回 null，注入的脚本第一行就抛，
   dump 里从来没有读数。判据本身也是错的：它按"dump 里搜得到标记字样"认"跑过了"，而 `--dump-dom`
   会把注入的**源码本身**一并吐出来，所以标记一直搜得到。三重修法：锚点换成今天的
   `#deskStream` / `#deskInner`（并在页面里选不到时**主动抛**）；读数标记由 `'PR'+'OBE'` 两段拼出，
   不执行就凑不出；`main()` 按四档窗口宽度量，补一条以前根本没量的**横向溢出**。
   `contract-consistency.mjs` 加三颗钉子盯着这件事（M12–M14 全验过）。

### 4.2 浏览器臂：本轮在容器里真跑通了（仍未进闸门）

`test/preview/browser.mjs`（新）统一做浏览器发现与 headless 参数：
`BROWSER_PATH`/`EDGE_PATH` → 平台已知安装位 → PATH 轮询 chromium / chromium-browser /
google-chrome / microsoft-edge / msedge / brave；参数固定带 `--disable-dev-shm-usage`，
`--no-sandbox` **只在 uid=0 时加**（普通机器上不许替所有人拆掉浏览器沙箱）。
四个手跑脚本（`csp-probe` / `legacy-artifact-csp` / `slot-cut-probe` / `measure-layout.py`）都改走它。

实测跑通（本沙箱 `/usr/bin/chromium`，64MB `/dev/shm`）：
- `csp-probe.mjs`：两臂对照全绿（fetch 被禁、外链图被禁、内联 script / `new Function` / `data:` 图照跑）。
- `legacy-artifact-csp.mjs`：对既有制品是纯 no-op（只多注入的那 1 条 meta）。
- `slot-cut-probe.mjs --seed`：真浏览器量出讲稿带与顺排落位（「顺排落在画面下沿：没被裁、没盖住画面」）。
- `measure-layout.py`：1912 / 1440 / 1180 / 900 四档全 PASS。

新的一条容器环境事实：**`--user-data-dir` 指一份新目录时 headless 首启挂在网络组件初始化上**
（几十秒不返回，甚至永不返回），不给这个参数同一页面 0.4–0.7 秒就 dump 完。
`measure-layout.py` 因此改成"先试独立 profile，超时退回不带 profile 再试一次"，两次都不回才判量不到。

**闸门决定不变**：这条臂仍然不进 `test:all`。CDP 与像素在本沙箱仍是随机崩的那一档，
装一个会随机红的闸门比没有闸门更糟——本轮做的是"换机器也能发现浏览器"，不是"让它当裁判"。

## 5. 遗留（记在案）

1. 浏览器臂不进闸门这件事本身还在：`test/preview/*` 现在可移植了（上面 4.2），但没有一条
   CI 口径能证明它"在这台机器上量到了什么"。要么哪天给它一档稳定的真浏览器 runner，
   要么接受它永远是手跑凭据——本轮选后者并写进 README。
2. `measure-layout.py` 的量是"几何"不是"观感"：字号、对比度、颜色仍靠上一轮的静态账与肉眼看。
   像素断言没有做。
3. `slot-cut-probe.mjs --live`（真模型回合）本轮没跑：沙箱里没有配好的订阅，`--dry` 就明说
   "一个订阅都没配好"。这条臂的模型侧仍欠一次实拍。
4. 撞名修复给的是 `-r<序号>` 递增，上限 1000 档；理论上同一毫秒坏出 1001 种不同内容会留不下
   第 1001 份证据（会明说"副本名全部被占"而不是静默丢）。没为它写钉子——造不出可信的复现。
