# 第四十六轮：对话窗口的证据保全——学习者亲口的话只增不减

> 日期：2026-10-25（用户本地）
> 基线：`e7468fd`（第 45 轮，文档层收敛）
> 判决依据：第一性原理（老师需要什么）+ 实测探针（先证伪再动手）+ 奥卡姆剃刀（确定性机制，不调模型）

## 一手依据：探针先证伪

- **现状**：`agent.mjs` 的 `windowHistory` 在历史超过 40 条后只保留「开头第一条用户消息（锚点）+
  最近一段」，中间的旧轮静默让位。窗口只作用于模型输入，落盘一字不少——但**模型不知道自己丢了什么**。
- **探针证伪**（`test/preview/window-evidence-probe.mjs`，改造前）：一局 56 回合的真实感会话，
  学习者在第 8 回合自述「我之前在别的教程里学过回调，但总把闭包和回调搞混」——这条被窗口静默丢掉。
  恰好是最不该丢的那一类：**学习者亲口说的话**。提问作答另由事件账本（execAsk → progress 事件）持有，
  结构化层唯独不捕获的就是学习者的自由输入（自述背景、解释、质疑、自己说出的误解）——
  老师的判断和下一步讲解都从这句话长出来。
- **为什么以前没修**：第十一轮起「对话摘要压缩（LLM）」维持候选五次——LLM 摘要会编造、
  失效、牵动契约，与「证据是私人财产、机械事实不掺模型判断」的原则相抵。本轮的判决是：
  **不要 LLM 摘要，要确定性保全**。讲解轮可以让位（结构状态在图谱/笔记里，每回合注入），
  学习者自己的话让位了才是真丢。零模型轮、零幻觉风险、纯机械选取。

## 方案

**窗口从「开头 + 最近一段」扩成「开头 + 窗口外学习者亲口的话 + 最近一段」，总条数恒等于上限：**

- **选取规则（确定性，不看语义）**：窗口外 `role=user` 且内容非空的旧轮，按时间序取最近至多
  `MAX_KEPT_LEARNER_MESSAGES`（8）条，插在锚点之后、最近段之前。
- **固定点收敛**：预算没用满时，把省下的额度还给最近段（最近段变长），再对变长的最近段重新收集
  （只会更少、不会更多）；kept 非增、recentLen 非减，≤ 预算轮次内收敛。总条数仍严格等于
  `MAX_DIALOGUE_MESSAGES`（40）——模型输入有界，契约不破。
- **锚点不动**：学习起点永不让位、永不去重（与旧行为一致）。
- **边界如实记录**：极端密度（学习者回合全是填充）下预算封顶，最早的自述让位给更近的学习者原话——
  探针把这条行为也摆出来，不假装全能保。

## 验证

- **全量六套件 2756 项断言全绿**（`npm run test:all`：run 705 / runtime-unit 92 / contract 403 /
  web-smoke 1264 / http-smoke 249 / artifact-evidence 43；基线 2746，+10 为 12e 新增）。
- **变异三连（先红后恢复，全部还原后重跑全绿）**：
  1. 删掉 `role === 'user'` 选择条件 → 「唯一那条窗口外自述被保全」「自述插在锚点之后」当场失败；
  2. 预算失去封顶 → 「窗口外超预算的旧学习者轮不进来」当场失败；
  3. 固定点被砍（只走一轮不收敛）→ 「预算没用满时最近段变长」「锚点与最近段重叠时不重复计」当场失败。
- **探针如实展示**：真实教学节奏（老师主讲、学习者隔段发言）下三条学习者自述全部保全；
  极端填充密度下预算封顶、最早自述让位（行为在案，不假装全能保）。
- **既有契约零漂移**：`contract-consistency.mjs` 403 项通过（README 解析目标全在收敛区之前）；
  `http-smoke` 249 项通过（服务端路径含 SSE 未受影响）。
