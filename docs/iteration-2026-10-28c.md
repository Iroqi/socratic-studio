## 一手依据：写协议漏掉的那一格，恰好是教学基线

第四十九轮把窗口写协议定为：「学习者说出关键自述 / 背景 / 约束 / 误解时，**当场写进结构层**：
知识点用 compile_notes，观察与记仇用 set_progress_state 的 session_note 或概念 note」——
结构层三个格子点名了笔记 / 进度，**漏了画像**（`meta.learner_profile`：background /
known_concepts / pace）。

而画像正是最先被窗口丢掉、又最驱动适配的事实：窗口只保「开头一句 + 最近一段 + 学习者亲口的
至多 8 条」，一段 40+ 回合的长对话里，学习者第 3 回合说的「其实我早学过统计」一旦不在那 8 条
预算里，模型从此只剩默认画像——`main.md` 第 80 行「未声明按初学者」。结果是：模型按初学者
讲了一整节，而他早说过自己会——这正是写协议要防的「丢了你读不到，也不能装作记得」的换脸版
（这次不是"装作记得他说过"，是"装作他没说过"）。

`main.md` 原有的句子只覆盖了**表现不符**（「后续表现不符可随时下调」），没有覆盖**学习者主动
改口**（"这个我会 / 我其实不懂这块"）——主动改口恰恰是最贵的信号：它在教学上等价于一次即时
的基线校正。

## 方案

1. **prompt.mjs 窗口写协议补一格**：写协议句尾追加——
   「背景 / 已掌握概念 / 节奏这类画像事实——包括改口（"其实我早学过 / 这个我会"）——当场写进
   meta.learner_profile，别等窗口把它丢掉」；并补一句「画像只写学习者亲口说过的事实，不猜着补」。
2. **main.md「学习者水平」合并改写**：原「…（预掌握初始化见 runtime.md「Concept 初始化」，
   后续表现不符可随时下调）」+ 新句合并为「…（预掌握初始化见 runtime.md「Concept 初始化」）；
   表现不符或学习者改口（背景 / 已掌握概念 / 节奏）时当场更新对应槽位，别沿用旧画像当基线；
   拿不准的不猜着写。」——语义不变、字数更省。
3. **run.mjs 新增 12q 节**（+6 断言）：画像进写协议、改口点名、旧协议两格未丢、
   画像钉在事实上、main.md 教改口、main.md 给省略纪律。

## 过程中发现并修掉的两个真问题

- **规则注入预算被击穿（64943 → 超 65000）**：main.md 新增行把 rulesBlob 顶过
  `RULES_CHAR_BUDGET`。按守卫自己的哲学「谁把规则写胖了谁红，不许悄悄调数字」，没有改预算，
  而是（a）把 main.md 新行与旧括号合并改写（省 ~30 字）；（b）压缩 protocols.md 画像格式句
  （「`learner_profile` 在文本载体里写成缩进块：`learner_profile:` 独占一行」→「文本载体里
  `learner_profile:` 独占一行起缩进块」，省 ~23 字，语义不变）——最终实测 64989 ≤ 65000。
- **年表探针在 origin 上连红三轮**：第 52–54 轮加了 README 年表行但没推
  `test/preview/table-archive-check.mjs` 的行数上限（停在 27，实际 30）——探针脚本本身不是
  test:all 套件，谁都没抓到。本轮一并收编：推进到 31（25–55），注释写明原因。
