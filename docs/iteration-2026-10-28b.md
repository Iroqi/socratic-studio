# 第五十四轮：图表诚实性——柱子的长度就是值

> 日期：2026-10-28（用户本地，同日第二轮，档案名 28b）
> 基线：`9de7b5f`（第 53 轮，问句是界面）
> 判决依据：一手博文（OpenAI GPT‑6 的 Intelligent UI，界面按 clarity / usefulness / completeness 评估）+ 几何审计（柱状图零基线 / 单位 / 静态图数据表）+ 奥卡姆剃刀（零新增档 / 状态 / `data-*`，只补一个纵轴函数、一个 `unit` 字段、一条既有 `table` 的适用面）

## 一手依据：界面要"经得起看"

Intelligent UI 把界面质量的评估标准写成 clarity、usefulness、completeness。图表是最容易
在这三项上作弊的一类界面：坐标轴截断能让 40% 的差距看起来像 10 倍，而像素本身不会
声明"我从 96.8 起画"。第 50–52 轮已经把"结果可核对"（算式 / 代入 / 前提 / 来源）和
"数据读得出来"（数据表 / 文字替代）补齐；这一轮补的是同一件事的另一半：**画出来的
几何本身必须忠实于数据**。

## 审计：100 / 120 / 140 画成了 11 / 80 / 111 px

| 缺陷 | 现象 | 根因 |
|---|---|---|
| **柱状图纵轴从数据最小值截断** | `series: 收入 = 100,120,140` 的柱高约 11 / 80 / 111 px：1.4 倍的数据差看起来约 10 倍。截图实测（修复前）可见三根柱子从"看不见"跳到"接近满格" | 第 31 轮把折线的自适应范围（`mn-pad … mx+pad`）直接复用给柱状图；柱子的**长度**是值，不是位置 |
| **纵轴不说单位** | 图上只有 100 / 120 / 140，标题也没写单位；"元 / 公斤 / 万人"全靠对话上下文猜 | chart 没有 `unit` 字段（calculator 从第 50 轮就有） |
| **静态图不能配数据表** | `table:` 只许交互档；静态图只有宿主补的 `.sr-only` 表，眼睛看得见图、想逐项核对时反而没有可见表 | 第 34 轮把 `table` 定义成"跟着快照走"，静态图被排除在外 |

第三处的根因值得说清：`table` 的价值不是"交互图的一部分"，而是**同一份数据的第二种
表示**。静态图同样需要它；把归属从"带 slider 的 chart"放宽到"chart"，实现上只是把
已有的表体生成器接到静态分支，不新增任何状态。

## Brainstorm：候选表与判决

| 候选 | 价值 | 成本 / 风险 | 判决 |
|---|---|---|---|
| **柱状图零基线 + 零线 + `unit` + 静态 `table`**（本轮） | 高：几何不再撒谎；单位不再靠猜；静态图也能逐项核对 | 低：一个 `chartDomain()` 供两条编译路径共用；`unit` 只进标题 / 读屏名 / 表标题（不加 `data-*`）；`table` 复用既有 `details` 结构 | **做** |
| 折线图也强制零基线 | 低：折线表达趋势，压到零轴会把 3→5→4 压成贴轴的平线 | 中：破坏第 31 轮起的所有折线用例 | 不做（按形状分开处理） |
| 柱状图纵轴从"好看的整数"起（1/2/5 刻度） | 中：更像出版级图表 | 中：要引入刻度算法与更多标签，超出本轮；零基线与比例已经解决"撒谎" | 维持（候选） |
| 单位写进每个轴标签（`100 元`） | 中：读数时不用回看标题 | 中：左轴宽度有限，长单位会挤爆；与"同一件事只出现一次"冲突 | 不做（标题 + 表标题各一次） |
| 静态图也画零线 | 低：静态柱状图同样可能有正负 | 低 | **做**（与交互档共用 `ui-chart-zero`） |
| 让模型自己保证基线 | 低 | 高：几何是宿主算的，模型只给数；把数学正确性押在提示词上就是没押 | 不做 |

## 方案

1. **`chartDomain(type, groups)`**：柱状图纵轴强制含 0（全正 `0 … max+pad`，全负
   `min-pad … 0`，混合两端各留 8%）；折线图保持原自适应。全零柱给 `0 … 1` 兜底，
   不除零。静态多系列与交互快照共用同一函数（两处实现迟早漂）。
2. **零线**：柱状图纵轴跨零时画 `<line class="ui-chart-zero">`（虚线，`--ink-3`），
   柱子从零线向两侧长；全正 / 全负不画（零线就是底轴 / 顶轴）。
3. **`unit`（≤12 字）**：标题旁标一次（`每月收入（单位：万元）`；无标题时单独一行
   `单位：万元`）；读屏名带一份；隐藏 / 可见数据表的 `<caption>` 带一份。单位是轴的
   口径，不是新的状态，不写 `data-*`。
4. **静态 `table`**：静态图也能写 `table: 表名`（≤40 字），图下长出与交互档同构的
   `<details class="ui-chart-table">`；一行一个系列。写了可见表就不再叠 `.sr-only`
   隐藏表（同一件事只出现一次）；不写仍是原来的隐藏表。
5. **拒绝语修正**：其他档写 `table` 的报错从"只配带 slider 的 chart"改成
   "只配 chart（静态图查全部数值，交互图跟着快照走）"——旧话在新事实下是假话。
6. **零新增面**：不加档、不加状态、不加 `data-*`、不改 `server/rules/`；新增的
   `.ui-chart-zero` 是编译器吐出的唯一新 class，样式在同一份 token 里。
