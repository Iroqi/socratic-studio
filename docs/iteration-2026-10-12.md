# 迭代记录 — 2026-10-12（第二十六轮）：图解也有形状了——diagram 那一档，学 Intelligent UI 的"解释复杂概念→图解"，不学它的交互

上一轮：`docs/iteration-2026-10-11.md`（第二十五轮，回答本身就是界面，commit `637c307`）。
本轮起点是 OpenAI 随 GPT-6 提出的 **Intelligent UI** 里最常被点名的那个用例：
「解释复杂概念时，可以生成交互式图解」（媒体实测里最出彩的也是它——讲麻将直接摆牌、
讲架构直接画分层图）。对照本仓第二十五轮立下的四档（`compare` / `steps` / `checklist` /
`calculator`），图谱上缺的正是这一格：**几个东西之间怎么连**。

这一轮把 `diagram` 加进封闭词表，但**只借形状、不借交互**——图是静态的，
学习者对图的交互在对话里。理由与逐条判决见 §2、§6。

---

## 1. 现状盘点（先跑，再撞）

基线 `637c307`（第二十五轮）上跑全部六支套件：6/6 绿，**2268 项**（web-smoke 871 /
contract 319）。本轮先补了一次环境账：克隆出来的树没有 `node_modules`，拉起真服务的
`http-smoke` / `artifact-evidence` 两支套件 30 秒等不到 `LISTENING` 直接 CRASH——
那不是断言变红，是服务压根没起来。`npm install` 之后基线回到 2268 / 6 绿。

撞出来的事实：

- **`diagram` 是词表里唯一缺的那一格**。`compare` 讲并列、`steps` 讲次序、`checklist`
  让学习者自己勾、`calculator` 让参数活起来——"解释一个系统 / 一段机制 / 一层结构"
  没有形状。而那正是 Intelligent UI 最常演示的场景。
- **静态形状不需要任何新接线**。`diagram` 像 `compare` / `steps` 一样没有"学习者在里面
  做过什么"这回事：不进 `UI_STATEFUL`、不落 `artifact_state`、不写 `data-*`、服务端
  零改动。第二十五轮的宿主接线（委托监听、回报通道、hydration、开关）一行都不用碰。
- **通用行数墙与档内上限会打架**。`compileUiBlock` 有一道 `MAX_ITEMS + 6 = 46` 行的
  通用墙（防"这一段把整篇文章塞进来"）。若按"够画一张大图"把上限拍成 24 节点 / 36 边，
  光行数就 60+，会被通用墙先拦下，档内上限成了摆设。所以节点 / 边都定 20（20 + 20 +
  2 = 42 ≤ 46），两道墙互不打架。上限是可数的，不是拍脑袋。
- **同一层内的边在"最长路径"分层下不可能出现**。`layer[v] = max(layer[u]) + 1` 时，
  `u -> v` 会让 v 的最长路径至少 +1——所以线永远从左往右，不用画回头弯。这是设计捡来的
  便宜，不是实现折衷。

## 2. 头脑风暴：候选方向一览

| 候选 | 判决 | 理由 |
| --- | --- | --- |
| 加 `diagram` 档：`node: 名字 [\| 一句话]` + `edge: 甲 -> 乙 [\| 说明]`，DAG 分层布局，内联 SVG，静态形状 | ✅ 做 | 图谱上缺的那一格；"解释复杂概念→图解"是 Intelligent UI 的旗舰用例；静态形状可复用第二十五轮全部宿主接线，服务端零改动 |
| 交互式图解（点击 / 悬停高亮邻接） | ❌ 否决 | 本仓没有"视图型交互"先例——静态形状与"学习者作答状态"之间没有中间态；DOM 桩测不了点击，测不了的正向钉子就是假绿。且 OpenAI 自己说"对话仍是控制层"：学习者指着图问"这里为什么这样连"，是模型接着讲。假交互（看着能点、点了没后果）比没交互更糟 |
| 图上挂 callout（`callout: 节点 \| 思考题`） | ❌ 否决 | 那等于往图上放题，向"判分藏进控件"那边滑了一步；若以后真要"节点附思考题"，那是新 kinds 的新契约，不是这一档顺手补的 |
| `timeline` 档（步骤带时长锚点） | ❌ 否决 | `steps` 已经覆盖有序过程，时长是 niche；每加一档都要连同降级路径、无障碍形状、契约测试一起加，边际收益不值 |
| `form` 档（表单收集输入） | ❌ 否决 | 收答已有 `ask_user_question`（阻塞回合、作答交回手里）；表单要么复制它要么造一条新回报通道，而 `checklist` 冒充提问已经被第二十五轮明令禁止 |
| `calculator` 扩词法（除法 / 括号 / 函数） | ❌ 否决 | 第二十五轮明确记在遗留里的词法封闭代价；想表达比例就写乘法，表达不了的走 `share_artifact` |
| 宿主强拦"一轮最多一个界面" | ❌ 否决 | 那是"渲染器替内容把关"，与本仓"制品只给现象，不判对错"的分工不同侧；维持提示侧自律 |
| `ui_done` 事件（清单勾满时报一条） | ❌ 否决 | `done` 快照已经注入下一轮，模型读得到；新事件 = 新契约，而这一档的承诺是"走已有通道" |
| `diagram` 进 `UI_STATEFUL` / 落 `artifact_state` | ❌ 否决 | 静态形状没有"学习者做过什么"这回事；记"看过哪张图"是新契约，不是这一档的缺漏 |
| 学 OpenAI 的 70 个组件 | ❌ 否决 | 封闭词表的意义是"可枚举 → 可机械校验 → 可读回给模型"，数量不是目标；第五档补的是**形状缺口**，不是朝自由度挪一步 |

## 3. 方案与实施

### 3.1 编译器：`web/ui-compile.js`（+182 行）

`UI_KINDS` 加 `diagram`；`compileDiagram(fields)` 与两个助手（`hashText` / `fitText`），
`COMPILERS` 加 `diagram: compileDiagram`。语法与硬规矩：

- `node: 名字 [| 一句话]`：身份就是名字——**重复声明直接拒绝**（`「甲」写了两遍`），
  节点名 ≤40 字、一句话 ≤80 字（超长**拒绝**而不是静默截断：数据截断与显示截断是两件事）。
- `edge: 甲 -> 乙 [| 说明]`：一条边只连两个节点；两端必须先在 `node` 里声明过，
  **没声明过就点名掉回原文**（`「丙」没在 node 里声明`）；自环、重复边分别点名。
- **必须是 DAG**：Kahn 最长路径分层，有环就掉回原文并说明回路 / 反馈走 `steps` 或正文。
- 数量上限 20 节点 / 20 边（见 §1，跟通用 46 行墙对齐）。
- **几何由输入决定**：层序从左到右、层内按名字排，同样的输入两次编译长得一模一样——
  流式那一路每帧重编，坐标跳来跳去的图没法对着问为什么。箭头 marker 的 id 由内容
  FNV-1a 哈希决定（`ui-arrow-<hash>`），同一份图重画仍是同一个、不同内容的图不共用。
- 渲染为内联 SVG：`<svg class="ui-diagram" role="img" aria-label="关系图解：…">`，
  `<title>` 在 svg 开头（读屏先念这一句）；节点的一句话落进节点 `<title>` 悬停；
  **读屏名里连节点 / 边数量都不放**（结构数量不是学情指标，但"数字不许进界面面"
  这条对读屏用户也该成立）。
- 静态形状：不要求 `id`、不进 `UI_STATEFUL`、不写任何 `data-*`——第二十五轮的
  `data-*` 契约测试一行不用改。

### 3.2 样式：`web/styles.css`（+12 行，7 条规则）

`.ui-diagram` 及其节点 / 连线 / 标注全用已量过的 token：节点底 `--surface-2`、名字 `--ink`、
一句话 `--ink-2`、连线与箭头 `--ink-2`、边注 `--ink-3`（落 `--bg`）。一条十六进制都没有。
几何（坐标、尺寸）全部由编译器按输入决定，样式只负责上色，没有 hover/active 那一族
（静态形状没有交互态）。

### 3.3 提示：`server/prompt.mjs` `APP_ADAPTER`（词表四档 → 五档，规则零字符）

表里加 `diagram` 行（`node` / `edge` 字段、用途"系统机制、调用链路、因果先后"）；
硬规矩从三条变四条：新第 3 条讲 `diagram` 的声明 / 无环 / **图是静态的，学习者对图的
交互在对话里**（他指着图问，你接着讲，别在图上加按钮、加"答案键"）。`server/rules/`
一字未动，`loadRulesText()` 仍 64,962。

### 3.4 测试：`test/web-smoke.mjs` §40（+51 项）+ `contract-consistency.mjs`（+7 项）

- §40「图解」：合法输入编成 SVG（节点矩形 / 箭头 / 读屏名 / 节点 title）；几何钉死
  （两节点图 `viewBox="0 0 312 80"`、先左后右）；十五条降级逐条点名；流式占位与"未闭合
  但合法照编"；XSS 转义（节点名 / 边注 / 属性位）；渲染器接线；词表口径（在名单、不是
  交互档、不在否决名单、没有判分位置）；简洁模式整段掉回原文；对比度三组 × 两套主题现算。
- contract 的 §13 是自动从源码抠名单的：`UI_KINDS` 加一档，提示表逐行点名、编译器
  函数存在、样式类一一对应这些检查**自己长出 +7 项**（1 个 kind 检查 + 6 个新样式类检查），
  并把"提示那张四档表"的文案改成"词表"（五档了，文案不许撒谎）。
- 另外把 §39 那条"降级理由里带可用档"从四档子串更新为五档全串（子串本来也能过，
  但钉的是"可用档名单"，就该钉完整名单）。

## 5. 实施与验证过程中翻出来的（原设计里没有）

1. **变异驱动也会写出"假绿变异"**。m7 第一版把计数器写成 `globalThis.__seq26 = …; const arrowId = …`
   的**独立语句**——语句跑了，但计数从没拼进 id，变异是个 no-op，套件照样全绿。
   教训：锚点唯一性预检只证明"字符串真的被替换了"，证明不了"行为真的被破坏了"。
   变异驱动也要对自己的变异负责：替换完之后先确认它**在行为上动了手**，再数红。
   （这一条与第二十五轮 m20 那条"红与崩是两件事"是同一族教训：验证手段本身也会假绿。）
2. **行数墙与档内上限的冲突在写代码之前就撞见了**。24/36 的"够用上限"撞上通用 46 行墙，
   档内上限成了摆设；改成 20/20 后两道墙对齐。上限不是拍脑袋的，是两条约束的交点。
3. **最长路径分层白捡一个性质**：同一层内不可能有边，所以边全是左→右直线，不用画
   回头弯 / 曲线。设计上没有为它多写一行代码。
4. **`aria-label` 连结构数量都不放**。节点 / 边计数不是学情指标，但把"数字不进界面面"
   这条在可见面上立住之后，读屏用户不该成为第一个看见数字的人。aria 里只有人话。
5. **note 超长拒绝而不是截断**。显示截断（格子装不下，收短 + 省略号，完整内容在
   `<title>` 悬停里）与数据截断（丢了就找不回）是两件事；这一档只允许前者发生。
6. **m5 靠措辞钉子抓到**。自环检查删掉后，环检查会兜住（自环本身是环），"有没有降级"
   验不出这枚变异——但 §40 钉的是具体原因措辞（`是自己连自己`），措辞变了照样红。
   降级原因的可枚举措辞不是给人看的装饰，是变异测试的锚点。

## 6. 有意没学 OpenAI 的那几处

抄来的（机制层面）："解释复杂概念 → 图解"这个用例本身；边生成边编译（宿主本来就有）；
界面是模型输出的一部分而不是另起的产物；用户侧"只要文字"开关对全档生效。

刻意不抄的（每条都对着本仓某条不变量）：

| OpenAI 那一手 | 本仓的选择 | 为什么不抄 |
| --- | --- | --- |
| 交互式图解（可点、可高亮、参数可调） | 静态 SVG，交互留给对话 | 本仓没有"视图型交互"先例，DOM 桩测不了点击，测不了的正向钉子就是假绿；OpenAI 自己说"对话仍是控制层"，学习者指着图问、模型接着讲，才是苏格拉底那一手 |
| ~70 个原生组件、界面由模型自由组合 | 封闭词表第五档，词表外一律退回原文 | 封闭才谈得上机械校验；可枚举才谈得上"这轮放的界面编译过没有"是可判定事实 |
| 学情侧可视化（进度、百分比一类） | 明名单九档永不做（第二十五轮） | Invariant 4 违规指纹①；diagram 的 aria 里连结构数量都不放 |
| 组件状态跨会话即清（"threads 是独立现实"） | 有状态的两档持久（第二十五轮）；diagram 无状态可续 | 本仓契约是"凡产出具交互性的制品，其作答状态必须能被下一轮读到"；diagram 不是交互制品，所以它**没有**状态，这不是比 OpenAI 松，是这一档本来就没有"学习者做过什么" |
| 提示注入面 = 模型生成的控件即攻击面 | 词法封闭 + 全量 HTML/属性位转义 + 无 `eval` / `new Function` + 服务端零新写面 | 攻击面按"能被说出的话"计数，SVG 里也没有脚本位 |

至于模型会不会真用 `diagram`、以及会不会因此少写散文——faux 测不出教学体感，
这条只能请用户开一局看（与第二十五轮收尾同一口径）。

## 7. 遗留（记在案）

- **边的说明有显示截断**：比格子间距长的边注会收短 + 省略号，而 `<title>` 悬停只挂在
  节点上，边的完整说明没有可悬停的位置。若以后要给边也挂 tooltip，那是渲染细节，
  不是这一档的缺漏——别顺手补。
- **同一份图在页面出现两次时 marker id 相同**（由内容决定）：两个同 id 的 `defs` 无害，
  但不算干净。要分实例得让编译器知道"这是第几块"，那要动 `markdown.js` 的块计数——
  按"别为好看加口子"的原则留着了。
- **图上不挂 callout / 思考题**：若以后要"节点附思考题"，那是新 kinds 的新契约，
  连同降级路径、无障碍形状、契约测试一起加。
- **20 节点 / 20 边是上限**：教学图解够用；想画更大的图走 `share_artifact`。
- **模型会不会真用这一档、会不会因此少写散文**：faux 测不出教学体感，请用户开一局看。
- 上轮遗留（config 字段级损坏、quarantine / jobs 目录不在体检内、uploads 记录与盘不一致、
  `topic/goal/learner` 无写通道、回合 epoch）维持原样。
