# Socratic Studio
NotebookLM 式一对一学习应用：教学规则住在 `server/rules/` 每回合注入 system prompt；内联界面（IUI）一等公民——16 档组件即教学工具，正文始终包成界面文本块；深色为主、浅色可切。
## 跑起来

```bash
npm start          # → http://127.0.0.1:8787
npm run test:all   # 6 套件全量验证
```
